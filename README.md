# User Dashboard (Pet Project)

Пет-проект для демонстрации навыков современной Frontend-разработки. Представляет собой дашборд для просмотра, поиска и управления пользователями.

## Стек технологий

- **React 18** + **TypeScript**
- **Vite** (сборщик)
- **Redux Toolkit** + **RTK Query** (стейт-менеджмент и работа с API)
- **React Router DOM v6** (навигация)
- **Feature-Sliced Design (FSD)** (архитектура)

## Ключевые фишки проекта

- **Архитектура FSD:** Код разделен на слои (`app`, `pages`, `features`, `entities`, `shared`) для легкости масштабирования.
- **Работа с API:** Использован RTK Query для кэширования запросов и автоматического управления состояниями загрузки (`isLoading`, `isError`).
- **Глобальное состояние:** Избранное реализовано через классический `createSlice` из Redux Toolkit.
- **Оптимизация рендеринга:**
  - Карточка пользователя обернута в `React.memo` (предотвращает лишние перерисовки).
  - Фильтрация списка обернута в `useMemo`.
- **Кастомный хук `useDebounce`:** Задерживает поиск на 300мс, чтобы не нагружать браузер при вводе.
- **Динамический роутинг:** Переход на страницу конкретного пользователя (`/user/:id`).
- **Строгая типизация:** Типизирован Redux (через `RootState`), API-ответы и пропсы компонентов.
